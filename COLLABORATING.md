# Совместная работа над «Тахи»

Откройте клон общего приватного репозитория в Codex и Reasonix. Начинайте каждую задачу с актуальной ветки `main`.

```sh
git switch main
git pull --ff-only
git switch -c feature/название-задачи
```

Для каждой задачи создавайте отдельную ветку. Перед отправкой запустите `npm test`, сохраните изменения коммитом и отправьте ветку командой `git push -u origin HEAD`. Откройте Pull Request в `main`, укажите, что проверили и что осталось. Ссылка на черновик Pull Request подойдёт для передачи промежуточного результата.

Чтобы проверить ветку коллеги, сначала выполните `git fetch origin`. Обсуждение и решения сохраняйте в Pull Request. Локальные изменения становятся доступны коллеге после отправки ветки.

Для запуска используйте инструкции из [README](README.md). Каталог, исходные фотографии, ключи и веса моделей держите вне Git. Если для задачи нужна модель, приложите команды для её установки и укажите версию в Pull Request.
